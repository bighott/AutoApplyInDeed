# Drop your resume here

Put your resume in this folder as **`.pdf`, `.md`, or `.txt`**. Any file(s) you
add here (except this README) are read at scoring time and used as the "skills /
experience" ground truth for matching jobs.

- `.md` / `.txt` → read directly.
- `.pdf` → parsed with `pdf-parse` (installed automatically). If PDF parsing
  fails on your machine, export your resume to Markdown or plain text instead.

You can drop more than one file (e.g. `resume.pdf` + `highlights.md`); they're
all concatenated. This folder is gitignored, so your resume never gets committed.
